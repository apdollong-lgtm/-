# ระบบค้นหาข้อมูลออนไลน์

โปรเจกต์ตัวอย่างระบบค้นหาข้อมูลออนไลน์แบบง่าย โดยเรียก Wikipedia OpenSearch API และแสดงผลผ่าน CLI

## การใช้งาน

```bash
python cli.py "ปัญญาประดิษฐ์" --limit 3
```

## โครงสร้างไฟล์

- `search_system.py` แกนหลักของระบบค้นหา
- `cli.py` โปรแกรมบรรทัดคำสั่ง
- `tests/test_search_system.py` ชุดทดสอบพื้นฐาน
